First release of docker-tidy: see what Docker keeps that nothing uses, and clean it up
safely.

## What you can do

- `docker-tidy` opens a terminal screen with a tab for containers, images, volumes and
  networks. Each row says whether it is unused and why. Tick what you want gone, press
  `c`, read the exact `docker` commands, and confirm.
- `docker-tidy report` lists what is unused, with sizes (`--json` for scripts, `--all`
  to include what is in use).
- `docker-tidy clean` shows the commands it would run. Nothing is removed until you add
  `--yes`.

## Safety

- It never offers a running container, the image a container was created from, a volume
  a container mounts, a network a container is connected to, or a built-in network.
- It never passes `--force` and never calls `prune`.
- Volumes are never ticked for you, and the dialog warns that removing one deletes its
  data.
- The confirm dialog opens on **Cancel**, so pressing Enter alone removes nothing.

## Install

You need Python 3.11 or newer and the `docker` command.

```bash
pip install docker_tidy-0.1.0-py3-none-any.whl
```

(download the wheel below), or from source as the README describes. It is not on PyPI.

Check the download against `SHA256SUMS.txt`. The files are not signed.

## Known limits

- Build cache is not listed or cleaned yet.
- An image's size is its full size, so "Reclaimable" over-counts images that share layers
  with ones you keep.
- Tested in CI against Docker Engine on Ubuntu, and on Windows and Linux with Python
  3.11 to 3.13 for everything that does not need a daemon. Docker Desktop on macOS and
  Podman are untested.
- It works on the Docker context your `docker` command is using now. Check which host
  you are tidying before you confirm.
